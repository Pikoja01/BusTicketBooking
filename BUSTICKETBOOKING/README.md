# Bus Ticket Booking

## Project Overview
This is a bus ticket booking web application built with Angular. Users can register, log in, select seats, and book bus tickets.

## Prerequisites
Ensure you have the following installed:
- [Node.js](https://nodejs.org/) (Latest LTS recommended)
- [Angular CLI](https://angular.io/cli)

## Installation
1. Clone the repository:
   ```sh
   git clone <repository_url>
   ```
2. Navigate to the project directory:
   ```sh
   cd BusTicketBooking/BUSTICKETBOOKING
   ```
3. Install dependencies:
   ```sh
   npm install
   ```

## Running the Application
To start the development server, run:
```sh
ng s --port 4209
```
Then, open [http://localhost:4209](http://localhost:4209) in your browser.

## Features
- User registration & login
- Seat selection and booking
- Local storage for session management

## Project Structure
- `src/` - Main source code
- `src/app/` - Angular components and services
- `src/assets/` - Static assets

## Notes
- Ensure the backend API is running if required.
- Modify `environment.ts` for API configurations if needed.
